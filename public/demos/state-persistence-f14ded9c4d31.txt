Share a file within one Pod

Actual commands and output captured in a disposable KubeQuest Kubernetes lab. Video is a condensed replay; the full transcript follows.

Inspect the starting environment
$ kubectl get pods,deployments,services,jobs -n quest
No resources found in quest namespace.


Complete the task
$ kubectl apply -f - <<'KUBEQUEST_YAML'
apiVersion: v1
kind: Pod
metadata:
  name: shared
  labels:
    run: shared
spec:
  containers:
    - name: first
      image: busybox:1.37
      imagePullPolicy: IfNotPresent
      command: &a1
        - sh
        - -c
        - sleep 3600
      volumeMounts:
        - name: data
          mountPath: /etc/foo
    - name: second
      image: busybox:1.37
      imagePullPolicy: IfNotPresent
      command: *a1
      volumeMounts:
        - name: data
          mountPath: /etc/foo
  volumes:
    - name: data
      emptyDir: {}
KUBEQUEST_YAML
kubectl wait -n quest --for=condition=Ready pod/shared --timeout=90s
kubectl exec shared -c second -- sh -c "cut -d: -f1 /etc/passwd > /etc/foo/passwd"
kubectl exec shared -c first -- cat /etc/foo/passwd

Why the repair works
emptyDir belongs to the Pod lifetime. It shares files between containers in that Pod but does not preserve data when the Pod is replaced.
