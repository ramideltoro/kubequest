Run behavioral checks
$ KubeQuest: Check my work
PASS Two ready application replicas — Keep two ready Pods labeled app=little-notes.
PASS Service selects the application — Match app=little-notes.
PASS Service port mapping — Expose 80 and route to the web port.
PASS HTTP request succeeds — An actual request must return HTTP 200.

Why the repair works
The Service selector used the old app name. A selector follows exact label values, so healthy Pods were never candidates. Changing the selector restores routing without restarting the workload.
