Actual commands and output captured in a disposable KubeQuest Kubernetes lab. Video is a condensed replay; the full transcript follows.

Inspect the starting environment
$ kubectl get pods,deployments,services,jobs -n quest

Complete the task
$ helm uninstall web
release "web" uninstalled


Run behavioral checks
$ KubeQuest: Check my work
PASS The Deployment is gone
PASS The release is absent

Why the repair works
Helm renders a chart’s templates using merged values, then stores release state in the cluster. This lab uses a small bundled web chart and a local repository so it works without public internet access.
