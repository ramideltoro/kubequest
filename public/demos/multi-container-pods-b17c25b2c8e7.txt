Choose the right container

Actual commands and output captured in a disposable KubeQuest Kubernetes lab. Video is a condensed replay; the full transcript follows.

Inspect the starting environment
$ kubectl get pods,deployments,services,jobs -n quest
No resources found in quest namespace.


Complete the task
$ kubectl apply -f - <<'KUBEQUEST_YAML'
apiVersion: v1
kind: Pod
metadata:
  name: double
  labels:
    run: double
spec:
  containers:
    - name: first
      image: busybox:1.37
      imagePullPolicy: IfNotPresent
      command: &a1
        - sh
        - -c
        - echo hello; sleep 3600
    - name: second
      image: busybox:1.37
      imagePullPolicy: IfNotPresent
      command: *a1
KUBEQUEST_YAML
kubectl wait -n quest --for=condition=Ready pod/double --timeout=90s
kubectl exec double -c second -- ls > answer.txt

Why the repair works
The -c flag selects the container. Pod networking is shared, but each container still has its own root filesystem.
